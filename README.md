# Matrix Operations using Python

## Overview
This project demonstrates basic matrix operations using Python and NumPy. It allows users to create matrices of any size and perform common mathematical operations through a simple command-line interface.

## Features
- Create custom matrices
- Display entered matrices
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix transpose
- User-friendly menu-driven program
- Implemented using NumPy for efficient matrix computations

## Technologies Used
- Python 3
- NumPy
- Jupyter Notebook

## Learning Outcomes
- Understanding matrix representation in Python
- Performing matrix arithmetic using NumPy
- Working with user input and multidimensional arrays
- Implementing menu-driven Python programs
